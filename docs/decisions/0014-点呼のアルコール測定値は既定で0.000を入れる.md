# ADR-0014 点呼のアルコール測定値は既定で 0.000 を入れる

- 状態: accepted（2026-11-18）
- 決めた人: 杉原氏（「アルコールはデフォで0いれといて」）
- 関連: ADR-0013 の決定1（既定値をやめる）を置き換える。ADR-0013 の他の決定（必須の確認項目・チェックの切り替え・定期点検・日常点検・JS/CSS の更新時刻）はそのまま

## 決定
- 乗務前・乗務後点呼のアルコール測定値は、最初から 0.000 を入れる。0 でなかった時だけ、測定した値に直す。
- 空にして登録することはできない（ADR-0013 のまま）。
- 「酒気・薬物の影響はないか」など必須の確認項目は、付けないと登録できない（ADR-0013 のまま）。確認した、という操作はこちらで残る。

## 理由
- ほぼ毎回 0.000 で、毎日1回余分に押す手間のほうが大きい（半日で差し戻し）。

## 残ること
- 測定値の欄だけを見ても、測ったかどうかは分からない（ADR-0013 の背景に書いた点は残る）。
