# ADR-0015 点呼でアルコールが出ても登録は止めず、赤で知らせて運行管理者に出す

- 状態: accepted（2026-11-25）
- 決めた人: Clio（タスク「WTS 全画面点検の所見」の判断待ちの点検 R-159 で「Clio が決める」とされた。案＝止めずに記録＋赤の警告＋運行管理者へ知らせる）
- 関連: ADR-0013（「0.15 以上で止める」を未決で残した）、ADR-0014（既定 0.000）

## 決定
1. 測定値が **0.000 より大きい**時は「アルコールが出た」とみなす。境目は `WTS_ALCOHOL_ALERT_ABOVE`（functions.php）1か所。判定は `isAlcoholDetected()`／SQL は `wtsSqlAlcoholDetected()`。
2. **登録は止めない。** 出た値をそのまま記録に残す（止めると、測った事実が残らない・0 に打ち直す誘因になる）。
3. 入力中に 0 より大きい値を入れると、欄の下に赤い注意が出る（`renderAlcoholLiveWarningScript`）。
4. 保存した記録の値が 0 より大きい時は、乗務前・乗務後点呼の画面の上に赤い知らせを出す（乗務前＝乗務させない・運行管理者へ連絡・測り直し）。
5. ダッシュボードに、直近7日に出た点呼を1件ずつ「点呼でアルコール検出」（最優先）で出す＝運行管理者への知らせ。

## 境目を 0.15 にしなかった理由
- 0.15mg/L は道路交通法の酒気帯び運転の基準。事業用の点呼で「酒気を帯びた状態」は、この基準以下かを問わない、という国交省の解釈があると理解している。**ただし 2026-11-25 に通達の原文（旅客自動車運送事業運輸規則の解釈及び運用について）は文字化けで引用まで確かめられていない。** どちらの読みでも 0 を境にすれば安全側になるため、0 を採った。
- 測り直しで 0 に下がった時は、もう1回記録すれば知らせは消える（前の値は変更の記録 logAudit に残る）。

## 却下した案
- 0.15 以上で登録を止める: 止めた後の運用（乗務させない・再測定）が決まっておらず、値が記録に残らない。
- LINE・メールで運行管理者へ送る: WTS に送る口が無い。ダッシュボードで足りなければ別に足す。

## 見張り
- ダッシュボードに「点呼でアルコール検出」が出た日に、乗務させていないか（運行管理者が確かめる）。
- 運転者の実機で赤い注意が見えるか（未確認）。
