# 管理者ガイド

会社・人・車・場所の登録と、陸運局への年次報告の出し方です。{{wts_name}}（<span class="url">{{wts_url}}</span>）に管理者のIDでログインして使います。

管理用の画面は、ダッシュボードを下にずらした所の **「システム設定」** から開く **マスタ管理メニュー** にまとまっています。

| マスタ管理メニュー | できること |
|---|---|
| ユーザー管理 | 運転者・点呼者などの追加・編集・パスワード再設定{{#haigo}}・配車の設定{{/haigo}} |
| 車両管理 | 車両の追加・編集、次回点検日・車検満了日の設定 |
| 会社情報設定 | 事業者名・代表者名・住所・許可番号など（陸運局への報告に使われます） |
| 輸送分類管理 | 「通院」「外出等」などの選択肢を増やす・並べ替える |
| 場所マスタ管理 | よく行く病院・施設を登録（入力のときに候補として出ます） |
| 書類管理 | 許可証・保険証券などのPDFを保管 |
| データ管理 | 試しに入れた記録の削除など |

## 1. ユーザー管理

### 人を追加する

1. ユーザー管理 → **追加**
2. 名前・ログインID・パスワード・権限（**管理者**か**一般ユーザー**か）を入れる
3. 職務を選ぶ（**運転者／点呼者／点検者／管理者／整備者** のうち最低1つ）
4. 保存 → 本人にIDと初期パスワードを伝え、初回ログインで変えてもらう

運転者にすると **乗務員台帳**（生年月日・入社日・免許の番号と有効期限・介護資格・健康診断・適性診断など）を入れる欄が出ます。期限が近づくとダッシュボードでお知らせします。

{{#haigo}}
### 配車（HaiGO）の設定 ― 運転者ごと

運転者の編集画面の下のほうに **「配車（HaiGO）」** 欄があります。HaiGOの配車ボード・自動振り分けはこの設定を見て動きます。

| 項目 | 意味 | 入れ方 |
|---|---|---|
| 配車ボードの担当色 | 配車ボードやカレンダーでその人の予約に塗る色 | 色を選ぶ。「自動（指定しない）」なら自動で色が決まる |
| 自動振り分けの優先順位 | 自動振り分けで先に割り当てる順番 | 1が最優先。空＝順位なし |
| いつもの担当車 | その人がふだん乗る車 | 車を選ぶ。**「なし」の人は自動振り分けの対象外**（手で割り当てる） |
| 曜日シフト | 曜日ごとの メイン／サブ／休み。祝日の休み | 全部「—」なら曜日シフトは使わない（全員が対象） |

> HaiGOの自動振り分け画面で順番を並べ替えて確定すると、ここの優先順位も書き換わります。
{{/haigo}}

## 2. 車両管理

1. 車両管理 → **追加**（または一覧の編集ボタン）
2. 車両番号・車両名・車種・登録年月日・乗車定員・走行距離を入れる
3. **福祉車両の区分**（車椅子・寝台・兼用・回転シート）を選ぶ（陸運局への第21号様式に使われます）
4. **次回点検日**（3か月点検）と **車検満了日**（車検証の「有効期間の満了する日」）を入れる

| 期限 | お知らせ |
|---|---|
| 次回点検日 | 近づくと一覧で色が変わります |
| 車検満了日 | **満了60日前からダッシュボードに表示**。切れたら「この車両で運行しないでください」と出ます |

## 3. 会社情報設定

事業者名・代表者名・郵便番号・住所・電話・運行管理者・許可番号・事業種別などを入れます。**陸運局への年次報告の表紙にそのまま使われる**ので、正確に入れてください。第21号様式用の「前年度の福祉タクシー車両の台数」「計画内容」もここで入れます。

## 4. 場所マスタ管理

よく行く病院・施設・駅などを登録しておくと、乗車記録{{#haigo}}やHaiGOの受付{{/haigo}}で名前の一部を打つだけで候補に出ます。

1. 場所マスタ管理 → **追加**
2. 名前（例: ○○病院）・ふりがな・郵便番号・住所を入れる
3. 保存

{{#haigo}}> **施設に入居している利用者さん** は、HaiGOの利用者の編集で「入居先」にこの施設を選べます。施設からの予約のとき、その施設の入居者の中から名前で本人を見つけやすくなります。{{/haigo}}

## 5. 陸運局への年次報告（第4号様式・第21号様式）

毎年 **5月31日** までに、前年度（4月〜3月）の実績を運輸支局へ提出します。ダッシュボードに期限のお知らせが出ます。

1. ダッシュボード →「陸運局提出へ」（またはメニューの陸運局報告）
2. **1. データを集める** … 前年度の乗務記録・事故の件数などを自動で集計します
3. **2. 内容を確認する** … 数字は直接直せます（事業概況・輸送実績・事故件数・福祉タクシー車両）
4. **3. ダウンロードして提出** … 第4号様式・第21号様式を **PDF** か **Excel** で出力して提出
5. 提出したら状態を **「提出済み」** にする（お知らせが消えます）

> {{wts_name}}を使い始めた日より前に終わった年度は、お知らせの対象になりません。

## 6. 書類管理・データ管理

- **書類管理**: 許可証・保険証券・車検証などのPDFを登録しておくと、監査のときにすぐ出せます
- **データ管理**: 試しに入れた記録の削除など。消した記録は戻せないので、本番の記録を消さないよう注意してください
