# 受付・配車ガイド（HaiGO）

電話で予約を受けて入力し、誰がどの予約に行くかを決めて運転者に知らせるまでの使い方です。

<span class="url">{{haigo_url}}</span>

- ログインIDとパスワードは **{{wts_name}}と同じ** です（ログイン画面に「ログインID（WTSと同じ）」と出ます）。ログインは90日間保たれます
- 画面の下（パソコンでは上）に4つのタブがあります

| タブ | 画面 | 何をする |
|---|---|---|
| **受付** | 受付クイック入力 | 電話を受けながら予約を入力し、復唱して確定 |
| **ボード** | 配車ボード | 前日に担当を割り振り、確定して運転者に一斉に通知 |
| **予定** | 予定カレンダー | 月で全体を見て、日を選ぶと時間割 |
| **乗務** | 今日の乗務 | 運転者が自分の配車を確認する（運転者ガイド参照） |

> 画面の中に「**スマルト**」と出てくる所は、{{wts_name}}のことです。{{#simulator}}料金の目安の金額は画面に固定で出ている参考値です。正式な料金は料金シミュレーターと貴社の料金表をご覧ください。{{/simulator}}

## 1. 予約を受ける（受付クイック入力）

電話を受けながら上から順に入れて、最後に画面下の **復唱パネル** を読み上げて確定します。

### ① いつ

1. **日付** … 「今日」「明日」「あさって」を押すか、日付を選ぶ
2. **時刻** … 「時」を選んでから「00」「15」「30」「45」を押す。まだ決まっていないときは **「時間仮」** を押す
3. **所要** … 「30分」「1時間」「1時間半」「2時間」（最初は1時間）
4. 日付を選ぶと **空き時間帯のボタン** が「午前」「午後」に並びます
   - 緑＝余裕あり、黄＝「残り1台」。押すとその時刻が入ります
   - 「この長さで入る空きがありません」と出たら、その日のその長さでは空きがありません
5. **空き状況** の帯（7時〜19時）で、運転者ごと・車ごとの予定の詰まり具合が見えます。指定した時刻に赤い縦線が入ります
6. 時刻を入れると、その前後の予約が並びます。「時間調整OK」の方がいると「電話」ボタンが出るので、ずらしてもらえるか頼めます

<div class="shots"><figure class="shot"><img src="img/haigo-quick-when.png" alt="日付を選ぶと空き時間帯が出ます" loading="lazy"><figcaption>日付を選ぶと空き時間帯が出ます</figcaption></figure></div>

### ② お客様（利用者名）

1. お名前を **ひらがなで** 打つ（例: 「たな」）→ 候補が出る
2. 候補の「○○様」と **住所（市・町名）** を見て、本人を選ぶ
   - **同じお名前が2人以上いるとき** は、前回の行き先（「前回 ○○→○○」）も出ます。住所と前回の行き先で見分けてください
3. 選ぶと **「前回のご利用」** が出ます
   - **「同じ内容で」** … 前回の行き先・機材・介助・人数・備考がまとめて入ります（時刻は「時間仮」で入るので、確認して直す）
   - **「逆区間（お帰り）」** … 行きと帰りを入れ替えて入ります
   - 「お久しぶり」と出たら、行き先や機材が変わっていないか確かめてください
4. メモがある方は「📌」で表示されます（例: 玄関に段差あり）

<div class="shots"><figure class="shot"><img src="img/haigo-quick-customer.png" alt="ひらがなで打つと候補が出ます" loading="lazy"><figcaption>ひらがなで打つと候補が出ます</figcaption></figure><figure class="shot"><img src="img/haigo-quick-previous.png" alt="選ぶと「前回のご利用」が出ます" loading="lazy"><figcaption>選ぶと「前回のご利用」が出ます</figcaption></figure></div>

**はじめてのお客様**：候補から選ばずにお名前を打ち、**住所か電話番号のどちらかを必ず入れて** ください。保存したときに利用者として登録されます。住所も電話も無いと、予約だけが入って利用者としては登録されません（次から候補に出ません）。

> 「○○様は既に登録があります（住所）。同じ方なら上の候補から選んでください」と出たら、同じお名前の方がもう登録されています。同じ方なら候補から選び、別の方なら住所を入れて区別してください。

### ③ 行き先・機材・介助

| 項目 | 入れ方 |
|---|---|
| 乗車地・降車地 | 「自宅」ボタン、前回の場所のボタン、または打ち込み。「⇅」で入れ替え |
| 移動の目安 | 「🚗 移動 約○分」と出ます。所要が足りなさそうなら「所要を○○に」を押すと直ります |
| 機材（車いす） | 「なし」「車いす」「リクライニング」「ストレッチャー」。選ぶと「持ち込み」か「レンタル」かを聞かれます |
| 介助 | 「室内介助」（人数）・「階段介助」・「院内介助」。**院内介助はその運転者の時間を2時間確保し、外注には回せません** |
| 乗車人数 | 本人＋付き添いの人数（最初は2名） |
| 担当 | 決まっていれば運転者を選ぶ（決まっていなければ「未定」のまま。配車ボードで決めます） |
| 復路（お帰り） | 「復路あり」→「1時間後」〜「3時間後」または時刻を選ぶ。まだ決まっていなければ「時間仮」のまま |
| 依頼元 | 「病院」「本人」「家族」「ケアマネ」と、病院名・事業所名 |
| 備考 | 電話番号・病棟・付き添いなど |

> ストレッチャーや4名以上のときは「ハイエース必須」と出ます。これは **大きい車が要る** という意味です（貴社の大きい車に読み替えてください）。

### ④ 復唱して確定

1. 画面下の **「▶ 開いて読み上げ」** を押す → 「○月○日 ○時○分ごろ、○○様。○○のご自宅から○○へ…」という文が出るので、**そのまま読み上げて** お客様に確かめる
2. **「復唱して確定」** を押す（乗車地・降車地まで入っていないと押せません）
   - まだ細かいことが決まっていないときは **「仮押さえ」**（日時とお名前だけで押せます。後で続きを入れる）
3. 空きが無いのに受けるときは「⚠ 空いていませんが確定」→ もう一度押すと確定します

<div class="shots"><figure class="shot"><img src="img/haigo-quick-readback.png" alt="読み上げる文が出ます" loading="lazy"><figcaption>読み上げる文が出ます</figcaption></figure></div>

保存しても **日付だけは残る** ので、同じ日の予約を続けて入れられます。

### 同じ予約を別の日にも入れる（定期の通院など）

保存したあと出る **「他の日にもコピー」** を押し、カレンダーで日を選んで **「○日にコピー」**。曜日の見出しを押すと、その月の同じ曜日をまとめて選べます。復路もいっしょにコピーされます（担当はコピーされません）。

### お客様の情報を直す

お客様を選んだあと **「✏️ 名前・メモを直す（顧客情報を編集）」**。名前・ふりがな・電話・住所・メモ・時間調整OK を直せます。

- **入居先**（施設・病院に住んでいる方だけ）: 施設名で探して選びます。施設からの予約のとき、その施設の入居者の中から名前で本人を見つけやすくなります。自宅に戻られたら「外す（自宅に戻った）」
- 名前を直すと、これからの予約の名前も変わります（過去の記録は変わりません）

## 2. 担当を決める（配車ボード）

前日に、次の日の予約に担当を割り振って確定します。上のタブで日付を選び、「担当別」か「時間順」で見ます。

<div class="shots"><figure class="shot"><img src="img/haigo-board.png" alt="配車ボード（担当別）" loading="lazy"><figcaption>配車ボード（担当別）</figcaption></figure></div>

### 手で割り振る

1. **「未割当」** の予約カードを押す → 詳しい内容が開く
2. **「担当」** で運転者（または外注先）を選ぶ
3. 運転者を選んだら **「車両」** も選ぶ
4. **「保存」**

前後60分以内にその運転者の別の予約があると「それでも割り当てますか？」と確認が出ます。

### 自動で割り振る

1. **「★ 自動振り分け」** を押す
2. 上に **運転者の優先順位といつもの車** が出ます。「↑」「↓」で順番を、右で車を変えられます（変えると案が計算し直されます。この順番は次から{{wts_name}}の設定にも残ります）
3. 予約ごとの案が出ます。違うものは「→」で選び直す（直したものには「手動」の印）
4. **「○件を割り当てる」** で確定

<div class="shots"><figure class="shot"><img src="img/haigo-auto.png" alt="自動振り分け。上で優先順位といつもの車を変えられます" loading="lazy"><figcaption>自動振り分け。上で優先順位といつもの車を変えられます</figcaption></figure></div>

> 自動振り分けは、{{wts_name}}の **ユーザー管理 → 運転者 → 「配車（HaiGO）」欄** の設定（優先順位・いつもの車・曜日シフト）を使います。「いつもの担当車」が「なし」の運転者は、自動では割り当てられません。

### 確定して運転者に知らせる

割り振りが終わったら、画面下の **「○日の配車を確定して通知」** を押します。運転者のスマホに通知が届き、運転者が「今日の乗務」で **確認ボタン** を押すと、ボードの見出しが「未確認」→「**確認済**」に変わります。

- 「○○さんは通知未設定。口頭で伝えてください」と出た人には、電話などで伝えてください（その人に通知を許可してもらうと、次から届きます）
- 確定したあとに内容や担当を変えると、その運転者に変更の通知が行き、確認が取り直しになります

### その他のボタン

| ボタン | 使う場面 |
|---|---|
| コピー（カード） | その予約を別の日にもコピー |
| キャンセル（カード） | 予約の取り消し。担当が決まっていれば運転者に取消の通知が行きます |
| 配車表をコピー | その日の配車表を文字でコピー。LINEなどに貼り付けて共有できます |
| 乗務記録にする | 乗った後、その予約を{{wts_name}}の乗車記録にします（料金・距離は分かる分だけ。後から{{wts_name}}で追加できます） |
| この日を乗務記録にする | その日の分をまとめて乗車記録にします |
| この日の割当をすべて解除 | その日の担当を全部「未割当」に戻します（運転者の「確認済」も消えます） |

画面の上に **「⚠ 間に合わない可能性」** が出たら、前の予約を降ろしてから次のお迎えに間に合わない組み合わせがあります。担当か時刻を見直してください。

## 3. 予定カレンダー

- 月の表示で、日ごとの予約の件数が見えます。**赤い点** はまだ担当の決まっていない予約がある日です
- 日を押すとその日の時間割（「ドライバー別」「車両別」）が出ます。「ボードで開く ›」でその日の配車ボードへ

## 4. 色の見方

| 色 | 意味 |
|---|---|
| 運転者ごとの色 | その運転者の担当（{{wts_name}}のユーザー管理で設定した色） |
| 緑 | 外注（手配済み） |
| 黄 | 外注予定（まだ手配していない） |
| 黒 | 未割当 |
| 薄い色・「⁉️」 | 時間が仮 |
