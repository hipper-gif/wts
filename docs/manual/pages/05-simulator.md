# 料金シミュレーター

お客様やご家族、ケアマネジャーさんが、**乗る前に料金の目安を自分で調べられるページ**です。ログインは要りません。

<span class="url">{{simulator_url}}</span>

## 使い方（お客様向けの説明）

1. **移動距離** を入れる（スライダーを動かすか、数字を入れる）。距離が分からないときは「Googleマップで距離を調べる」から調べられます
2. **機材の貸し出し** を選ぶ（使わない／車椅子／リクライニング車椅子／ストレッチャー）
3. **介助オプション** を選ぶ（室内介助・院内介助・階段介助・外出介助。人数や時間も選べます）
4. 当てはまれば **割増・割引** を選ぶ（深夜・早朝のご利用／障害者手帳をお持ちの方）
5. 右（スマホでは下）に **料金の目安** と内訳が出ます。そのまま電話ボタンから予約の電話ができます

> 表示されるのは目安です。道路状況や経路で実際の料金は変わります。

## 会社としての使い方

- ホームページ・チラシ・名刺に **QRコードやリンク** を載せる
- 電話で料金を聞かれたとき、**リンクを送る** と説明の手間が減ります
- ケアマネジャーさんや病院の地域連携室に紹介しておくと、見積もりの問い合わせが減ります

## 料金を変えたいとき

運賃・介助料・機材料金・迎車料金などを変えたときは、{{support_contact}} までご連絡ください。こちらで設定を変えます（変えた料金は、ページを開き直すと反映されます）。
