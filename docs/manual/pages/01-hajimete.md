## 3. スマホのホーム画面に追加する

どのシステムも、スマホのブラウザで開いて「ホーム画面に追加」すると、アプリのように使えます。毎回URLを入れる手間がなくなります。{{#haigo}}**HaiGOの通知を受け取るには、ホーム画面に追加してから開く必要があります（特にiPhone）。**{{/haigo}}

### iPhone（Safari）

1. 上のURLを **Safari** で開く（Chromeなどでは「ホーム画面に追加」ができないことがあります）
2. 画面下の **共有ボタン**（四角に上向きの矢印）をタップ
3. メニューを下にずらして **「ホーム画面に追加」** をタップ
4. 右上の **「追加」** をタップ

### Android（Chrome）

1. 上のURLを **Chrome** で開く
2. 「ホーム画面に追加」「インストール」の案内が出たらタップ
3. 出ないときは、右上の **︙（3つの点）** →「アプリをインストール」または「ホーム画面に追加」

{{#haigo}}{{wts_name}}とHaiGOは別々に追加してください（アイコンが2つになります）。{{/haigo}}

## 4. 初日にやること

### 管理者

- ☐ 別紙のIDでログインし、**初期パスワードを変更**する
- ☐ 会社情報を確認する（{{wts_name}} → システム設定 → 会社情報設定）
- ☐ 運転者・点呼者を登録する（ユーザー管理）
- ☐ 車両を登録し、**車検満了日**を入れる（車両管理）
- ☐ よく行く病院・施設を登録する（場所マスタ管理）
{{#haigo}}- ☐ 運転者ごとに **配車の設定**（担当色・自動振り分けの優先順位・いつもの車・曜日シフト）を入れる（ユーザー管理 → 運転者 → 「配車（HaiGO）」欄）{{/haigo}}

### 運転者

- ☐ {{wts_name}}{{#haigo}}とHaiGO{{/haigo}}をホーム画面に追加する
- ☐ ログインできることを確かめる
{{#haigo}}- ☐ HaiGOの「今日の乗務」で **通知を許可** する{{/haigo}}
- ☐ 1日の流れを一度試す（日常点検 → 乗務前点呼 → 出庫 → 乗車記録 → 入庫 → 乗務後点呼 → 売上金確認）

> 試しに入れた記録は、管理者が後から消せます（{{wts_name}} → システム設定 → データ管理 →「不要データ削除」）。気軽に試してください。

## 5. 困ったとき

| こんなとき | どうする |
|---|---|
| ログインできない | IDとパスワードを確かめる。5回間違えると15分ログインできません。管理者にパスワードを再設定してもらう |
| 画面が古いまま・おかしい | 画面を下に引っぱって再読み込み。直らなければアプリ（ホーム画面のアイコン）を閉じて開き直す |
{{#haigo}}| HaiGOの通知が来ない | 「今日の乗務」で通知を許可したか確かめる。iPhoneはホーム画面に追加したアイコンから開いているか確かめる |{{/haigo}}
| それでも分からない | {{support_contact}} までご連絡ください |
